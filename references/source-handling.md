# 多来源材料处理

## 来源职责

| 来源 | 主要用途 | 注意事项 |
|---|---|---|
| 录音或视频 | 还原语气、例子、限定条件和问答 | 只在歧义或重点段落需要时核听 |
| 转写稿或录音 PDF | 建立全文索引并快速提取主题 | 同音词、英文术语和说话人可能识别错误 |
| 教案或课件 | 补足知识框架、标准术语和教学顺序 | 不要用教案覆盖讲师明确表达的差异 |
| 飞书或其他在线笔记 | 识别已有重点、补充结构和上下文 | 在线内容可能更新，要基于实际读取版本 |
| 用户聊天要求 | 决定范围、结构、删改和发布方式 | 优先级最高 |

## 冲突处理

同一内容存在差异时，先判断是转写错误、表达层级不同还是实质冲突。

- 明显同音或拼写错误可直接修正，例如专业术语与上下文唯一匹配。
- 录音为课堂原话，教案为规范补充时，可以合并，并标明补充关系。
- 两个来源给出不同事实或数字时，不擅自选一个。核验可靠来源，仍无法确定则标注待核实。
- 用户明确要求删除的章节或主题不得因材料中存在而恢复。

## 面试内容识别

以下内容应归入面试章节：明确的面试题、简历或项目表达建议、回答结构、追问方式、评价候选人的标准以及讲师的面试复盘经验。

不要把普通课堂提问全部包装成面试题。只有能够考察能力、知识或经验迁移的问题才纳入，并说明考察点。

## 定义和行业认知识别

定义类内容需要给出边界和使用场景，避免用另一个陌生词循环解释。行业认知类内容应区分稳定规律、阶段性判断和个人观点；涉及易变化的市场事实时要核验并注明时间。
